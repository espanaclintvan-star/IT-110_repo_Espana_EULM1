parent-child

In this project layout, the parent-child relationships dictate how the elements are structured and nested. For instance, the <figure> element acts as a direct parent to the <img> element, which means any styles applied to the figure container can directly encapsulate or position the child image. Similarly, the <ul> (unordered list) element serves as the parent to multiple child <li> (list item) elements within the hyperlinks section. These nested structures allow the browser to parse the Document Object Model tree accurately, establishing a clear hierarchy where child elements inherit layout constraints from their direct parent containers.
